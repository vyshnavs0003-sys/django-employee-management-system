# Django Employee Management System

A Django-based Employee and Department Management System with CRUD operations, ModelForms, template inheritance, and static CSS.

## Features

- Add Employee
- View Employees
- Update Employee
- Delete Employee
- Department Management
- Template Inheritance
- Static CSS Styling
- Function-Based Views
- Django ORM

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite

## Project Structure

- Models
- Views
- Templates
- Forms
- Static Files
- URL Routing

## CRUD Operations

- Create
- Read
- Update
- Delete

## Run Project

```bash
python manage.py runserver
```
